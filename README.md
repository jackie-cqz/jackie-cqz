## About

I'm a student at **Beihang University**, currently interning at **Z.ai**. I work on AI systems, autonomous agents, and privacy-preserving machine learning, exploring the engineering that connects models to working systems.

My work spans planning and tool use for LLM agents, vision-language robotic manipulation, reinforcement learning for robot control, and fully homomorphic encryption for private inference.

### Current interests

- **Memory & context** — Persistent learning and contextual reasoning across sessions.
- **Agent collaboration** — Planning, coordination, and scalable multi-agent workflows.
- **Evolution & adaptation** — Self-improvement, feedback, and autonomous adaptation.

### Tech stack

`Python` &nbsp; `TypeScript` &nbsp; `C` &nbsp; `C++`
